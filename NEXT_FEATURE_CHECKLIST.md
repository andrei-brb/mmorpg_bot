## 2) Scope the MVP

## 3) Balance Rules
- [ ] Min/max caps defined
- [ ] Diminishing returns rules (if needed)
- [ ] Respec/reset policy

## 4) UX Rules
- [ ] Clear command help text
- [ ] Error messages and edge-case behavior
- [ ] Announcement behavior (if any)
- [ ] Progress visibility (profile, command, embed)

## 5) Technical Safety
- [ ] Migration plan (safe on existing data)
- [ ] Hook points identified (combat/quest/economy/etc.)
- [ ] Backward compatibility checked
- [ ] Logging/metrics included

## 6) Release Plan
- [ ] Internal test cases listed
- [ ] Rollout strategy (all at once or phased)
- [ ] Post-release watch items
- [ ] Rollback strategy
