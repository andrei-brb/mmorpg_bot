# MMORPG Bot - Feature Idea Vault

Last updated: 2026-03-17

## Status
These are brainstorming ideas (not approved yet). Keep here so nothing gets lost.

## Core Ideas

### 1) Class System Expansion
- Warrior, Mage, Rogue, Healer
- Each class has unique abilities and role identity

**Why it matters**
- Strong fantasy identity
- Better party composition and replayability

**Open questions**
- Keep current classes/specs and expand, or full redesign?
- How to avoid overlap between classes?

---

### 2) Skill Trees
- 3 branches per class
- Spend skill points to unlock abilities/passives

**Why it matters**
- Build diversity
- Long-term progression and player ownership

**Open questions**
- How many points per level?
- Cheap respec early / expensive respec later?

---

### 3) Prestige / Rebirth
- At max level: reset to level 1
- Gain permanent bonuses + cosmetic aura/title

**Why it matters**
- Endgame loop and retention
- Prestige identity/status

**Open questions**
- Hard cap on permanent bonuses?
- Unlock requirements and anti-power-creep rules?

---

### 4) Mastery Levels
- Weapon mastery by usage (e.g., sword, staff, bow)
- More use = higher mastery = small bonus

**Why it matters**
- Natural progression from gameplay behavior
- Adds depth without heavy UI complexity

**Open questions**
- Bonus cap and diminishing returns?
- Per-weapon-family vs per-weapon?

---

### 5) Stat Allocation
- Players assign points into STR/DEX/INT/VIT

**Why it matters**
- Classic RPG expression
- Supports different builds inside same class

**Open questions**
- Points per level?
- Recommended auto-build presets?
- How often can players respec?

---

## Suggested Rollout Order (Safe)
1. Skill Trees (light v1)
2. Mastery Levels
3. Prestige/Rebirth
4. Stat Allocation
5. Class System deep expansion

## Balance Guardrails
- Cap permanent power sources
- Use diminishing returns on stacked bonuses
- Always provide respec option
- Introduce one major system at a time

## Parking Lot (Future)
- PvP ruleset compatibility
- Party synergy passives
- Seasonal prestige ladders
- Cosmetic-only mastery rewards

## Next Decision Checkpoint
Before implementation, decide:
- [ ] Which feature ships first
- [ ] Numeric caps for power systems
- [ ] Respec policy
- [ ] MVP commands/UI for first release
