## 🎨 Icon Creation Notes

For creating PNG icons with Gemini:

1. **Consumables** - Focus on potion bottles, scrolls, and charms
2. **Equipment** - Create icons that represent the item type (sword, shield, helmet, etc.)
3. **Rarity** - Consider color-coding or visual effects to represent rarity tiers
4. **Size** - Recommended: 64x64 or 128x128 pixels for Discord compatibility
5. **Style** - Keep consistent art style across all icons

### Priority Items for Icons:
1. All 8 consumables (most visible to players)
2. Special named items (10 items)
3. One icon per equipment slot type (10 icons) - can be reused for all rarities
4. Optional: Unique icons for each rarity tier (5 icons)

## 🔗 Integration Notes

When integrating icons:
- Icons are stored in the `icon` column of the `item_templates` table
- Currently using emoji (e.g., '🧪', '⚔️')
- Can be replaced with file paths or URLs to PNG images
- Consider creating an `assets/items/` directory structure
