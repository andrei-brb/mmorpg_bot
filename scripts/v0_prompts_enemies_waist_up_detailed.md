# v0 prompts — enemies waist-up detailed (exact in-game names)

Use this file when generating enemy and boss portraits for combat.
All names/keys match `activity/src/data/zones.ts`.

## What the model must generate (for every prompt)

- Generate exactly **one** enemy character portrait asset.
- **Waist-up framing only** (from waist to head), keep face and weapon/claws readable.
- 2D anime/chibi fantasy RPG style, 3/4 view, clean line art, soft cel shading.
- Enemy slot orientation: **RIGHT side unit facing LEFT** toward battle center.
- Transparent background PNG.
- No UI/frame/text/watermark/logo/background scene/photorealism/3D/motion blur.
