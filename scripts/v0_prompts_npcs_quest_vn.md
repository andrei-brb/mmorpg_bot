One prompt per NPC. Filename after export: `activity/public/assets/npcs/{npc_id}.png`.

## Global style (prepend or merge into every prompt)

Readable at small width in a game UI portrait slot. Negative: no UI frame, no text, no watermark, no logo, no busy background scene, no photorealism, no 3D render, no blur, no extra limbs, no cropped face.
