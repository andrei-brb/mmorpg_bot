# v0 prompts — enemies waist-up detailed (PNG pipeline)

This is the PNG-path version of the detailed enemy prompts.

Use together with:
- `scripts/v0_prompts_enemies_waist_up_detailed.md` (full detailed prompt text per enemy)

---

## Generation requirements (same for every enemy)

- Generate exactly one enemy portrait asset.
- Waist-up only (waist to head), 3/4 view.
- Enemy orientation: RIGHT side unit facing LEFT.
- 2D anime/chibi fantasy RPG style, clean line art, soft cel shading.
- Transparent background.
- No UI/text/watermark/logo/background scene/3D/photorealism.

---

## Copy-paste template (PNG path included)

### Mob template
Generate a 2D anime/chibi fantasy RPG enemy portrait, waist-up only (waist to head), 3/4 view, enemy on RIGHT facing LEFT, transparent background PNG, clean line art and soft cel shading. Character: **[EXACT NAME]** with clear silhouette and readable combat expression. Save as: **`activity/public/mobs/[KEY].png`** (URL: **`/mobs/[KEY].png`**). Negative: no UI, no frame, no text, no watermark, no logo, no background scene, no photorealism, no 3D render, no blur, no extra limbs.

### Boss template
Generate a 2D anime/chibi fantasy RPG boss portrait, waist-up only (waist to head), 3/4 view, boss on RIGHT facing LEFT, transparent background PNG, clean line art and soft cel shading. Character: **[EXACT NAME]** with elite presence, stronger silhouette than mobs, signature weapon/effect visible in frame. Save as: **`activity/public/bosses/[KEY].png`** (URL: **`/bosses/[KEY].png`**). Negative: no UI, no frame, no text, no watermark, no logo, no background scene, no photorealism, no 3D render, no blur, no extra limbs.
