# v0 prompts — fantasy RPG waist-up portraits

Every item below is one single copy-paste prompt.

These prompts are tuned for:
- transparent background PNG
- 2D anime/chibi fantasy RPG style
- **waist-up portrait framing** (upper body only, no full body)
- 3/4 camera angle
- clean line art + soft cel shading
- combat-facing orientation for left/right battle slots

---

## Global style line (reuse in all prompts)

2D anime/chibi fantasy RPG portrait illustration, waist-up only (from waist to head), 3/4 camera view, clean line art, soft cel shading, crisp silhouette, transparent background PNG, consistent scale and outline thickness across the set. Negative: no UI, no frame, no text, no watermark, no logo, no background scene, no photorealism, no 3D render, no blur, no extra limbs, no cropped face, no cut-off hands if visible.
