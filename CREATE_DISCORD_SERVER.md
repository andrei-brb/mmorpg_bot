# 🏠 Create a Discord Server for Testing

## Quick Steps:

1. **Open Discord** (app or web)
2. **Click the "+" button** on the left sidebar (or click "Add a Server")
3. **Choose "Create My Own"** (or "Create a Server")
4. **Select "For me and my friends"** (or "For a club or community")
5. **Name your server**: `MMORPG Bot Test` (or any name)
6. **Click "Create"**
7. **Skip** the "Customize your server" step (or do it later)
8. **Done!** You now have a server

---

## Then Go Back to Authorization:

1. Go back to the Discord Developer Portal authorization page
2. Refresh the page if needed
3. Your new server should now appear in the dropdown!
4. Select it and click "Authorize"

---

## Alternative: Use Discord Web

If you're using the Discord app, you can also:
- Right-click on the server list → "Create Server"
- Or go to https://discord.com/app and create one there
